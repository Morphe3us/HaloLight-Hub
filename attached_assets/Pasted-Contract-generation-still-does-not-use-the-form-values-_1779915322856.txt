Contract generation still does not use the form values correctly.

Current bug:
The contract is created, but the generated contract content does not properly use the information I filled in the form.

Example:
If I fill:

* client details
* address
* event info
* service/package
* deposit
* price
* terms

The final generated contract still does not correctly reflect those values.

This means the form state is not correctly mapped into the contract template variables before save.

Please debug the real data flow:

Form fields
→ contractForm state
→ variable replacement map
→ generated content preview
→ API payload
→ saved contract content
→ detail/print view

Required fix:

1. Every visible form field must map to the correct contract variable.

Examples:

* clientName → {{client_full_name}}, {{client_first_name}}, {{client_last_name}}
* clientCompany → {{client_company_name}}
* clientEmail → {{client_email}}
* clientPhone → {{client_phone}}
* clientAddress → {{client_address}}

Provider:

* user company → {{rental_company_name}}
* user full name → {{rental_company_representative}}
* user email → {{rental_company_email}}
* user phone → {{rental_company_phone}}
* user address if available → {{rental_company_address}}

Event:

* eventDate → {{event_date}}
* eventStartTime → {{event_start_time}}
* eventEndTime → {{event_end_time}}
* eventLocation → {{event_location}}
* setupTime → {{setup_time}}
* pickupTime → {{pickup_time}}

* form state values
