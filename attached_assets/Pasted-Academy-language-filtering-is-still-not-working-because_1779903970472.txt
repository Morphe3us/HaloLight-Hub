* English
* Français
* Español
* Deutsch
* Italiano
* Português
* Polski
* Nederlands

This is intentional.

But the client Academy must NOT show all modules.

Required behavior:

Public/client Academy route `/academy`:

* Always show ONLY the module matching the current user language.
* This must apply even if the logged-in user is admin.
* Admin status should NOT bypass filtering on the public Academy client pages.

Admin Academy route `/admin/academy`:

* Admin can see and manage all language modules.

So:

FR user on `/academy`:

* show only module: Français
* show only French lessons
* course count = French lessons only
* progress = French lessons only

EN user on `/academy`:

* show only module: English
* show only English lessons

ES user on `/academy`:

* show only module: Español
* show only Spanish lessons

Same for:

* de → Deutsch
* it → Italiano
* pt → Português
* pl → Polski
* nl → Nederlands

Remove the admin bypass from public Academy endpoints/pages.

Admin bypass should exist only for `/admin/academy`, not `/academy`.

Because I am admin, `/academy` still shows all modules.
