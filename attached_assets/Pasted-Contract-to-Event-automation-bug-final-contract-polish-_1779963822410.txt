1. CONTRACT VALIDATION SHOULD CREATE / LINK EVENT
   ==================================================

Current issue:
When a contract is validated/signed/accepted by the client, the related event does not appear in the upcoming events dashboard.

Expected behavior:
When a contract reaches a confirmed status, the system should automatically create or link an Event.

Trigger:

* contract signed
* contract accepted
* contract status changed to signed/active/confirmed
* client validation if such status exists

Event should be created from contract data:

* event title:
  client name + event type
  Example: “Jeanne Duflo — Anniversaire”

* event type:
  from contract eventType

* event date:
  from contract eventDate

* start time:
  from contract eventStartTime

* end time:
  from contract eventEndTime

* location:
  from contract eventLocation

* linked contractId

* linked leadId if available

* linked quoteId if available

* linked client/customer info

* selected equipmentIds if available

* revenue/contract value

* currency

Important:
Do not create duplicate events.

If the contract already has a linked event:

* update the existing event instead of creating a duplicate.

If the user manually created an event before:

* try to detect/link by client email + event date + location.
* if uncertain, ask user or show “Link existing event” option.

Dashboard:

* upcoming events widget must include events generated from signed contracts.
* events must be sorted nearest first.
* past events should not appear as upcoming.

Verification:

1. Create contract with event date in the future.
2. Mark contract signed/validated.
3. Go to Dashboard.
4. Upcoming events should show the event.
5. Go to Events page.
6. Event should be visible and linked to the contract.
7. Mark contract cancelled.
