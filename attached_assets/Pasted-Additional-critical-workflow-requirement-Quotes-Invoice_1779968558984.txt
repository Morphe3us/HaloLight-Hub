Additional critical workflow requirement — Quotes / Invoices / Events / Consumables must reuse the full rental details.

The button issue is fixed, but we still need the full operational workflow.

The Sales workflow must not only create documents. It must prepare the real upcoming service operationally.

Current issue:
Quotes and invoices do not include enough rental details. They can show only a title/event name instead of the full service content.

Expected:
Quotes, contracts and invoices must all reuse the same complete rental/service information.

==================================================

1. QUOTES MUST INCLUDE FULL RENTAL DETAILS
   ==================================================

Quotes should include the full service/package content, not only the event title.

A quote should show:

Client:

* name
* company
* email
* phone
* address if available

Event:

* event type
* event date
* start time
* end time
* event location

Service:

* package name
* rental duration
* included prints
* digital gallery included yes/no
* custom template included yes/no
* delivery included yes/no
* setup included yes/no
* on-site operator included yes/no
* options/add-ons
* equipment/service description

Pricing:

* rental price
* options price
* delivery fees
* discount
* tax/VAT
* total
* currency

Expected:
When creating a quote from a lead or client, these fields should be fillable and saved.
When converting quote → contract, all these fields should transfer.
When converting quote → invoice, all these fields should transfer.

==================================================
2. INVOICES MUST INCLUDE FULL RENTAL DETAILS
============================================

Invoices should not only show a generic event title.

Invoices must include:

* event type

* package/service name
* rental duration
* included prints
* options/add-ons
* selected equipment if available
* delivery/setup/operator info

If invoice is created from contract:

* copy all quote service fields.

* allow filling these fields.

Print/PDF invoice should be clear enough that the client understands exactly what they are paying for.

6. CONSUMABLES FORECASTING
==========================

Consumables must be connected to upcoming events.

When a quote/contract/invoice/event includes prints:

* includedPrints = 200
  → reserve/forecast 200 prints worth of consumables.

If includedPrints is “unlimited”:

* treat as 600 prints by default for forecasting.

If includedPrints is empty:

* do not reserve automatically, but show warning:
  “Print quantity not specified.”

This should affect:

* upcoming event preparation
* consumables dashboard
* low stock alerts
* reorder recommendations

Expected:
If upcoming paid events require 1,000 prints total and stock is 700 prints:

* show warning:
  “Upcoming events require 1,000 prints. Current stock covers 700. Estimated shortage: 300 prints.”
